## Andrei

I build industrial systems end to end, from the PLC to the screen an
operator actually looks at. Second-year student at an ITS in AI and
digitalisation, after a placement in industrial automation.

**[FillerStack](https://github.com/RazAndAlex/FillerStack)** — the whole
data chain behind a rotary can filler: virtual PLC, OPC UA, Node-RED,
MQTT, Parquet, PostgreSQL, read-only API, dashboard. The field data comes
from a causal process model, so the diagnosis at the far end can be
scored. 567 tests, 21 ADRs. [Walk the chain →](https://razandalex.github.io/FillerStack/)

**[LineLens](https://github.com/RazAndAlex/LineLens)** — a local tool that
reads a machine event log and puts the naive number next to the honest
one. On the demo file: 87,000 seconds of declared downtime against 24,000
real ones.

Right now I am learning where OT stops and IT starts, and writing down
